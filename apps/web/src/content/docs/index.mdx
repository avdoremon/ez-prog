Reading that binary search is "O(log n)" teaches you the words. Watching the
search window collapse by half, step by step, on an array you picked yourself,
teaches you the idea. Every lesson here is built around that difference.

## How a lesson works

<CardGrid>
	<Card title="Watch it run" icon="seti:notebook">
		Every algorithm is a series of frames. Step forward and back, or play
		it through — each frame explains in one sentence what just happened.
	</Card>
	<Card title="Use your own input" icon="pencil">
		Open **Try your own input** under any visualization and run the
		algorithm on values you choose. Bad input is rejected with an
		explanation, never a blank screen.
	</Card>
	<Card title="Follow the code" icon="seti:javascript">
		The code panel highlights the line responsible for the current frame,
		so the picture and the source stay in step.
	</Card>
	<Card title="Check yourself" icon="approve-check">
		Each lesson ends with questions whose answers explain why the wrong
		options are wrong, and a link to practice the real problem.
	</Card>
</CardGrid>
